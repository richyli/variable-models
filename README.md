# 變數與理論模型工具

以 [Variable.base](../Variable.base) 的篩選條件（tags 含 `variable`）為基礎，把 `-work/Notes/` 裡的變數 note、理論 note 與它們之間的邊整理成一個離線互動頁。

- 開啟：直接用瀏覽器開 `index.html`（不必伺服器；資料已嵌在頁面裡）
- 重建：`python tools/variable_model_tool.py`（加 `--report` 會印出沒對到 note 的名稱、沒掛理論的變數）
- 設定：`variable_aliases.yml`（同義變數、類似變數、理論標籤對應、補充的標準模型）

## 頁面怎麼用

1. 左邊搜尋框（自變數）打字或從左側清單點一個變數。
2. 右邊搜尋框（依變數）會自動只剩「從左邊出發、在某個模型裡到得了」的變數；兩個都選了，頁面只顯示含這條路徑的模型，路徑打亮、其餘淡化。也可以先選右邊，左邊會列出能走到它的自變數。
3. 「理論模型」第一張是「上下游變數」總覽：左邊是影響它的變數、右邊是它影響的、下方是調節它的；每個變數旁並排來源理論的標籤（虛線框＝補充理論、「筆記」＝筆記裡沒標理論的關係），點標籤跳到那張模型圖。接著列出變數出現的每個模型，各一張概念圖；黃色＝自變數，藍框＝依變數，橘色＝類似變數，虛線＝補充的標準結構，點線＝調節。
4. 圖上任何節點都可以點，點了就改以它為中心；點模型卡左上的縮寫只看那個理論；瀏覽器上一頁可以回來。
5. 「使用類似變數的模型」列出沒有這個變數、但有它類似變數的模型。
6. 首頁上半是「補充的常見理論」索引（依領域分組），下半是 vault 裡的理論概念圖。
7. 每張模型卡依圖的寬度自動佔 1–4 欄；「⤢ 整列」可強制放大；頂列「☰ 清單」收合左側清單；清單頂端可勾「只列有 note 的變數」；按 `/` 跳到搜尋框；點標題回到首頁。

## 上下游圖的兩種模式

「上下游變數」卡右上角可切換三層：**單一變數**只看這個變數本身的邊；**相近變數**把近義變數併成一小群（例如「迴避」與「抗拒」是兩個不同的小群，定義在 `semantic_groups.yml` 各群的 `subgroups`）；**變數群**把整個語意群併成一群（例如「迴避與抗拒」合在一起）。變數頁「相關變數」也分三色：深橘＝相近變數、淺橘＝同變數群、藍虛線＝上下游結構相似（以「影響它的群」與「它影響的群」算 Jaccard 相似度，供分群時參考）。原本的說明：**變數群**把同義、近義的變數併成一群（例如「迴避與抗拒」收 User Resistance、AI Avoidance、Algorithm Aversion、Avoidance Motivation、Exit、Turnover Intention），中心與上下游都以群顯示，標籤合併。群的定義在 `semantic_groups.yml`（一個變數只能在一群，沒列的自成一群），與下面的主題群組是兩層不同的東西。任一側超過 10 個變數時，那一側改成兩欄清單（依理論數排序，符號在每項最前面），用一支箭頭連到中心。

每個理論的結構都附 2 到 4 個參考來源（模型卡右下「來源」、理論單頁「參考來源」），邊的結構依這些來源整理；`supplement_theories.yml` 裡每個理論的 `enrich_notes` 記錄查證時的取捨。

## 三層分類

變數的分類固定三層：**變數群**（例如「情緒」「規範」）→ **相近變數**（例如情緒底下的「愉悅」「恐懼」「焦慮與壓力」；規範底下的「外在規範」「內在規範」「制度與外部壓力」）→ **變數**（例如 Joy）。定義都在 `semantic_groups.yml`：每個 `groups` 項目是一個變數群，`subgroups` 是相近變數群，沒列進任何子群的成員自成一個相近變數群。變數頁的標題、側欄「群組」模式、上下游圖的三種模式都用這三層；`variable_aliases.yml` 的關鍵字 `clusters` 只在變數沒有語意群時當後備。

## 對照 Miles（2012）的缺口

`GAP_REVIEW_Miles2012.md` 逐章列出書中 40 個理論與我們的對照：原本缺的 19 個已新增、既有的 21 個補了書中的邊與變數。

## 變數群組（主題，後備）

每個變數會被歸進一個群組（轉換與留存、信任與可信度、AI 與演算法、品牌、廣告與口碑……共 22 群）。規則在 `variable_aliases.yml` 的 `clusters`：依序用正規表示式比對變數名與別名，第一個命中的群組就是它的群；要手動指定就在該群加 `members:`。變數頁的「相關變數」＝手動登記的類似變數（橘色）＋同群變數；左側清單可切成「群組」檢視；搜尋框也比對群組名。跑 `--report` 會印出每群人數與落到「其他」的變數。

## 量表（每個變數一頁）

`scales.yml` 收錄各構念的量表（出處、定義、題項、作答量尺、信度、原始情境、改編注意）。建置時產生兩種頁面：`questionnaires.html` 是**目錄**，依變數群分組列出所有有量表的構念；`scales/<slug>.html` 是**每個變數自己的量表頁**，左側列同一變數群的其他量表、右上可跳回理論模型裡的該變數。主頁變數卡上的「量表 N 份 ↗」直接連到該變數的量表頁，頂列「量表目錄」連到目錄。

## 經典模型的核心

`core_models.yml` 列出每個經典模型的核心變數（例如 TAM 的 PU、PEOU、Behavioral Intention、Behavior）。概念圖上核心變數用粗黑框、兩端都是核心變數的關係用粗黑線，延伸變數維持一般樣式；要替某個理論加核心，加一行「理論 id: [變數…]」即可。

## 兩個資料檔

- `variable_aliases.yml`：同義變數、類似變數、理論標籤對應、vault 理論的補充結構。
- `supplement_theories.yml`：vault 沒有 note 的常見理論（2026-10-16 起，含 AI 迴避、演算法厭惡等 AI 相關理論），每個理論有縮寫、中文名、領域、一句說明與邊；有 note 的理論用 `note:` 指回去就不算補充理論。

## 公開版與本機版

公開版（GitHub Pages）不放任何 `obsidian://` 連結與 vault 路徑。要在本機用帶「↗ 開 note」連結的版本，跑 `python tools/variable_model_tool.py --local-links`（這個版本不能 `--publish`）。

版面審查紀錄在 `UX_REVIEW.md`。og image 是 `og.jpg`（/gen-image 產的情景圖，寬 1200）。

## note 要怎麼寫才會被抓到

| 想表達 | 寫法（任一） |
|---|---|
| 這是變數 | frontmatter `tags: [variable]` 或內文 `#variable` |
| 這個變數屬於哪個理論 | `#T_TAM` 這類標籤，或連結 `[[T TPB  Planned Behaviroal]]`；標籤與理論 note 的對應在 yml 的 `theory_tags` |
| A 影響 B | `A --> [[B]]`、`[[A]] -> [[B]]`、`[[A]] ++ [[B]]`（正向）、`[[A]] -- [[B]]`（負向，兩邊都要是連結） |
| C 調節 A→B | `[[C]] ++ [[A]] to [[B]]`，或關係 note 裡寫 `Moderated by [[C]]` |
| 名稱不同但同一個變數 | frontmatter `aliases:`、連結顯示名 `[[Behavior\|Use]]`，或 yml 的 `same` |
| 意思相近但不合併 | 內文 `Similar to [[X]]`，或 yml 的 `similar` |

邊會掛在它上面最近一個理論標籤／理論連結的脈絡下；遇到標題行（`#`、`##`）脈絡就重設。理論 note（檔名 `T ` 開頭或 tags 含 `Theory`）本身也會被掃描。

## 兩種來源的邊

- 實線：note 裡寫的邊（滑鼠停在線上會顯示出處 note）
- 虛線：`seed_models` 補的教科書標準結構，只是為了讓只貼了圖的理論也有概念圖；不代表 note 裡寫過

要關掉補充結構，把 yml 裡對應理論的 `seed_models` 條目刪掉即可。
